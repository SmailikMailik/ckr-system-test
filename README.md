# CKR System Test

Проект выполнен в рамках тестового задания для студии «ЦКР Система».
В приложении на Unity реализованы кликер, прогноз погоды и каталог пород собак.

## Как открыть и запустить

1. Установите **Unity 6000.3.27f1** через Unity Hub. Версия проекта также указана в [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt).
2. Скачайте репозиторий через **Code → Download ZIP** и полностью распакуйте архив.
3. В Unity Hub выберите **Add project from disk** и укажите папку, в которой находятся `Assets`, `Packages` и `ProjectSettings`.
4. Откройте проект и дождитесь завершения импорта. При первом открытии потребуется интернет для загрузки стандартных пакетов Unity.
5. Откройте сцену **Assets/_Project/Scenes/Startup.unity** и нажмите **Play**.

## Что есть в игре

- **Кликер.** Нажимайте «Собрать», чтобы получать валюту и тратить энергию. Автоматический сбор и восстановление энергии работают во время игры.
- **Погода.** На вкладке отображаются текущий прогноз, температура и соответствующее оформление. Для получения данных нужен интернет.
- **Породы.** Прокручивайте список и нажимайте на название породы, чтобы открыть её изображение и описание. Для загрузки списка и описаний нужен интернет.
- **Сохранение.** Валюта и текущая энергия сохраняются локально и восстанавливаются при следующем запуске.

Между разделами можно переключаться нижними кнопками. Если загрузка данных завершилась ошибкой, интерфейс показывает её и позволяет повторить действие.

## Что было сделано

Реализованы игровые механики кликера, загрузка данных из двух внешних сервисов и локальное сохранение прогресса. Отдельный стартовый экран подготавливает данные пользователя перед открытием игры.

Интерфейс оформлен в общем стиле: подготовлены иллюстрации, иконки, кнопки, индикаторы загрузки, прокрутка и окно описания. Вёрстка адаптируется к разным пропорциям окна; поддерживаются мышь и сенсорный ввод.

Код разделён на игровые функции, интерфейс, получение данных и хранение прогресса. Для сетевых действий предусмотрены состояния ожидания, обработка ошибок и отмена устаревших запросов.
